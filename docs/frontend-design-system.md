# 邻里流转 · 前端设计系统

> 适用范围：`src/app/**`、`src/components/**`、`src/lib/**`。
> 执行状态：阶段 0 已落地全局 token、shadcn/ui、根布局与风格预览页。

## 1. 设计定位

**社区信任感 + 精品市集 + 轻 AI 助手。**

产品不是电商平台，也不是后台管理系统。页面要让用户快速完成：

```text
发现物品 -> 判断是否可领取 -> 发起申请 -> 确认预约 -> 完成交接 -> 归档
```

## 2. 视觉原则

- 通透：浅色背景、留白充分、层次靠间距和边框而不是大面积装饰。
- 克制：不使用电商大促风、科技暗黑风、玻璃拟态堆叠。
- 温暖：绿色代表循环与可信，琥珀色用于价格和重点动作。
- 清楚：物品状态永远比装饰醒目。
- 一致：同一状态在所有页面使用同一颜色和文案。

## 5. 字体与排版

- 中文：`Noto Sans SC`，英文数字：`Inter` / 系统字体。
- 页面标题：`28-36px`，半粗，不使用夸张大字。
- 区块标题：`20-24px`。
- 卡片标题：`16-18px`。
- 正文：`14-16px`，行高 `1.6-1.75`。
- 辅助信息：`12-13px`。
- 不使用负字距，不用全大写英文制造风格。

## 6. 页面结构

### 6.1 App Shell

顶部导航固定包含：

- 产品标识：邻里流转；
- 当前空间：小区 / 楼栋名称；
- 搜索入口；
- 发布按钮；
- 通知铃；
- 用户菜单。

### 6.2 首页

- 页面定位：快速发现当前可领取物品。
- 文案：`让闲置，在沉没前被看到。`
- 搜索框位于首屏可见区域。
- 筛选器使用胶囊组件：分类、交易方式、新鲜度、排序。
- 物品卡片保持稳定比例，建议图片 `4:3`。
- 卡片信息顺序：图片、新鲜度、名称、交易方式、价格、描述摘要、分类、发布者、申请数/收藏数。
- 移动端筛选项收进 Sheet，发布按钮保持可见。

### 6.3 发布页

- 宽屏左右结构：左侧表单，右侧 AI 助手。
- 左侧：名称、分类、描述、交易方式、价格、图片上传。
- 右侧：定价建议、描述润色、发布前检查清单。
- AI 建议支持“采用建议”和“重新生成”。
- 上传区是真实组件，支持预览、删除、排序、最多 6 张。

### 6.4 详情页

- 宽屏左侧图片画廊，右侧信息操作区。
- 状态区必须清晰显示：可领取 / 已预约 / 已送出。
- 申请人只能提交备注、期望时间和地点。
- 发布者可以查看申请、接受、拒绝、完成。
- 联系方式仅在申请被接受后显示。
- 下方公开留言板，AI FAQ 助手生成回复后可由发布者一键发送。

### 6.5 我的申请

- 使用 Tabs 区分“我发起的”和“我收到的”。
- 每条申请展示物品、申请人、留言、期望时间、地点、状态和操作。
- 操作按钮按状态出现，不显示不可执行按钮。

### 6.6 通知中心

- 轻量列表，未读项使用浅绿背景或左侧状态点。
- 图标区分申请、接受、拒绝、完成和归档。
- 空状态要给出返回首页或查看物品的入口。

### 6.7 数据看板

- 视觉像“社区周报”，不要像后台系统。
- 先展示本月发布、本月成交、当前在售。
- 再展示最快被领走、最想要等精选卡片。
- 首版以数字卡和列表为主，不堆大图表。

## 7. 组件规范

| 组件 | 规则 |
| --- | --- |
| Button | 主按钮绿色实心；次按钮白底边框；AI 按钮紫色描边 |
| Badge | 状态和新鲜度必须使用统一色，不随意增加颜色 |
| Card | 默认白底、细边框、轻阴影，hover 可轻微上浮 |
| Input/Textarea | 圆角 `10-12px`，focus 使用绿色 ring |
| Select | 与输入框一致高度和边框 |
| Sheet | 移动端筛选和轻量表单使用 |
| Dialog | 确认接受、拒绝、归档等关键操作使用 |
| Tooltip | 用于 AI 降级、权限提示和陌生图标 |
| Sonner | 所有写操作完成都给出 Toast 反馈 |
| Skeleton | 首页、详情、看板必须有骨架屏，不用全局转圈替代 |
| EmptyState | 一句说明 + 一个主 CTA，不使用冷冰冰“暂无数据” |

## 8. 动效规范

- 页面进入：淡入 + `8px` 上移，时长 `180-240ms`。
- 卡片 hover：上浮 `2px`，阴影增强。
- 按钮点击：缩放 `0.98`。
- Toast：从顶部进入，自动消失。
- AI 生成：显示“正在生成建议”，保留取消或重试入口。
- 禁止大面积滚动动画、背景视频、持续呼吸的装饰元素。

## 9. 无障碍

- 文本对比度不低于 WCAG AA。
- 状态不能只靠颜色表达，必须同时有文案。
- 图标按钮必须有 `aria-label` 或 Tooltip。
- 键盘可以完成加入、发布、申请、接受和归档主流程。
- 图片必须有有意义的 `alt`；装饰图使用空 `alt`。
- 表单错误与字段关联，错误文案说明如何修复。

## 10. 验收标准

- 首页第一眼能看懂物品是否可领取。
- 所有状态色和文案与本文一致。
- 发布、申请、接受、完成、归档主链路操作清楚。
- 空、加载、错误状态都有设计。
- AI 功能有质感但不抢主流程。
- 移动端无横向溢出。
- 不出现电商大促风、后台管理风、暗黑科技风。
